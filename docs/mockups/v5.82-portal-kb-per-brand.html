Uygulama · portal.html JS

// v5.82 — SPA ekranları için tarayıcı geçmişi entegrasyonu.
// Her show() çağrısı pushState ile URL'e yazar; popstate dinleyicisi
// browser back/forward tuşlarını yakalar.
function show(id, opts = {}) {
  document.querySelectorAll('.screen').forEach(s => s.classList.remove('active'));
  document.getElementById(id).classList.add('active');
  window.scrollTo(0, 0);
  // Yeni: URL'yi de güncelle (hash-based, sunucu değişikliği gerekmez)
  const hash = id === 's-landing' ? '' : id.replace(/^s-/, '#');
  if (!opts.fromPopState) {
    history.pushState({ screen: id }, '', hash || location.pathname);
  }
}
window.addEventListener('popstate', e => {
  const id = (e.state && e.state.screen) || 's-landing';
  show(id, { fromPopState: true });
});

Öneri · Varyant A

Üç varyantın da doğrusu var; ama Varyant A senin ilk önerinin en direkt karşılığı ve en düşük riskli. Assos'un mavi + İnventist'in siyah-beyaz dilinden çıkmayan, panel içinde 2 CTA barındıran, mevcut lookup kutusunu koruyan, backend'de sıfır ek endpoint gerektiren bir çözüm. Bir sonraki iterasyonda A'nın üzerine C'nin "top-3 önizleme" katmanını opsiyonel olarak ekleyebiliriz — o zaman /portal/api/kb/top?firm= endpoint'i devreye girer.

Back navigasyon fix'i (§04) tüm varyantlarda ortak — hangisini seçersen seç, aynı history.pushState yaması gider. Küçük ama etkili.
